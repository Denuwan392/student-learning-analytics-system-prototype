# PRAGNA — Student Learning Intelligence Prototype

Autonomous AI-Powered Student Learning Intelligence System for Sri Lankan GCE Advanced Level (A/L) education.

## Overview
This repository contains the standalone prototype web application for PRAGNA. It demonstrates closed-loop student monitoring, deterministic evidence guardrails, 365-day activity heatmaps, multi-role views, scenario simulations, and AI explainability.

## Features
- **Closed-Loop Intelligence**: Continuous observation $\rightarrow$ evidence $\rightarrow$ recommendation $\rightarrow$ human approval $\rightarrow$ outcome measurement.
- **Role-Based Access Control**: Tailored workspaces for Students, Parents, Teachers, Advisors, and Administrators.
- **Mobile Responsive Design**: Fully responsive navigation, mobile drawer sidebars, stackable metric cards, and touch-optimised interface elements.
- **Guardrailed AI Assistant**: Grounded in deterministic computation without hallucinated metric predictions.

## Getting Started
Simply open `index.html` in any modern web browser, or serve using a static web server:

```bash
# Using Python built-in server
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
